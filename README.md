检查Minecraft客户端以所指位置的9*9*9访问内是否存在幽灵方块并消除。

使用 U 键或 /ghost 以使用其功能。

必须在服务端和客户端安装！


原本gbl大佬有一个模组也是这个的，但是实测下来发现并没有作用，遂重新写了一个模组。
